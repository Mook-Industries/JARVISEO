# voice — 음성 입출력 · 담당 문태현

흐름: 웨이크워드 감지 → VAD 로 발화 구간 파악 → STT → (처리) → TTS

| 파일 | 하는 일 | 책임 지표 |
|---|---|---|
| `wakeword.py` | "자비서" 호출어 감지 | FAR / FRR |
| `stt.py` | 로컬 음성 인식 | — |
| `tts.py` | 응답 음성 합성 · 재생 | — |

## 알아둘 것

- **되먹임 루프 주의.** 스피커 소리를 마이크가 다시 듣는다. 재생 중에는 마이크를 막는다.
- `stt.py` 의 `started_at` 이 핵심이다. 이 시각으로 `capture` 가 프레임을 고른다.
- 상시 동작하는 부분은 클라우드에 올리지 않는다. 로컬에서 돈다.
