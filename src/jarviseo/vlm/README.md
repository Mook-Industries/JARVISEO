# vlm — 기본 계층 · 범용 VLM 호출

항상 먼저 동작하는 계층. 해당되는 특화 모듈이 있으면 맥락을 덧붙이고,
없으면 기본 응답이 그대로 나간다. 그래서 질문 주제에 제한이 없다.

| 파일 | 하는 일 |
|---|---|
| `client.py` | 클라우드 VLM 호출 |

## 알아둘 것

- **여기가 하이브리드 온디바이스의 경계선이다.** 네트워크로 데이터가 나가는 유일한 곳.
- 나가는 것은 질문 시점의 **1프레임(정확히는 타깃 크롭)** 뿐이다. 영상 스트림이 아니다.
- API 키는 `config.py` 를 통해서만 읽는다. 여기서 `os.getenv` 하지 않는다.
