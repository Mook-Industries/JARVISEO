# nutrition — ② 식품 성분 판정 · 담당 권용현

과자를 보고 "이거 뭐 들어갔어?" 하면 성분표를 찾아 읽고 등록된 알레르기와 대조한다.

| 파일 | 하는 일 | 책임 지표 |
|---|---|---|
| `detector.py` | 성분표 영역 검출 (YOLO 직접 학습) | 성분표 검출 mAP |
| `ocr.py` | ROI 크롭 → 업스케일 → 전처리 → OCR | OCR 인식률 |
| `allergen.py` | 성분 ↔ 알레르겐 대조 · 판정 | 알레르기 판정 recall |

## 알아둘 것

- **정밀도보다 재현율 우선.** 놓친 알레르겐과 과잉 경고는 피해가 비대칭이다.
- 입력은 `pointing` 이 확정한 타깃 크롭이다. 전체 프레임이 아니다.
- 성분표 원문(`ocr_raw_text`)을 반드시 남긴다. 틀렸을 때 어디가 틀렸는지 찾으려면 필요하다.
