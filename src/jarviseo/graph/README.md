# graph — LangGraph 오케스트레이션 · 담당 최홍묵

전체 흐름을 그래프로 묶는다.

```
호출어 감지 → 발화 시점 프레임 캡처 → STT → 의도 라우팅
  → (병렬) 객체 검출 · OCR · 기억 검색 → 지시 대상 특정
  → VLM 응답 → TTS
```

| 파일 | 하는 일 |
|---|---|
| `pipeline.py` | 노드와 분기 구성 |
| `state.py` | 그래프를 흐르는 상태 = **노드 사이의 계약** |

## 알아둘 것

- **개별 노드는 각 모듈의 함수를 부르기만 한다.** 로직을 여기 넣지 않는다.
  그래야 각자 자기 모듈만 고쳐도 되고 이 파일에서 충돌이 안 난다.
- 되돌아가는 분기 두 개: 프레임이 흐리면 `recapture`, 대상이 모호하면 `clarify`.
- `state.py` 필드 추가는 `types.py` 와 같은 규칙을 따른다.
