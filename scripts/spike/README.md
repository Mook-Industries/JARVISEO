# 기술 검증 (스파이크) 5종

W1(9/21~9/27)에 각자 돌려보고 성공 스크린샷을 팀 채널에 공유한다.
목적은 "된다/안 된다"를 확인하는 것이지 잘 만드는 게 아니다.
각 30줄 내외로 짧게 유지하고, 여기서 만든 코드는 본 모듈에 옮기지 않는다.

| # | 파일 | 확인할 것 | 담당 |
|---|---|---|---|
| 1 | `spike_01_capture.py` | 프레임이 들어오고 선명도가 계산되는가 | 전원 |
| 2 | `spike_02_stt.py` | 마이크에서 한국어가 글자로 나오는가 | C |
| 3 | `spike_03_vlm.py` | 이미지 1장 + 질문으로 답이 오는가 | A |
| 4 | `spike_04_graph.py` | LangGraph 노드 2개가 순서대로 도는가 | A |
| 5 | `spike_05_yolo.py` | 사전학습 YOLO 가 물체를 잡는가 (= baseline) | A, B |

5번은 단순 확인이 아니다. **여기서 나온 숫자가 baseline 이 된다.**
학습을 시작한 뒤에는 되돌려 잴 수 없으므로 반드시 기록하고
`docs/experiments.md` 의 baseline 표를 채운다.
