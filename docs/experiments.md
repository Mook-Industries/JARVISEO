# 실험 기록

모든 학습·측정을 여기 남긴다. 결과보고서가 이 파일에서 나온다.

## 기록 규칙

- **학습을 돌리기 전에** 먼저 한 줄 적는다. 나중에 몰아서 쓰면 설정을 잊는다.
- 실패한 실험도 적는다. 같은 실패를 두 번 하지 않으려고 쓰는 문서다.
- 숫자는 반드시 어떤 데이터셋(train/valid/**test**)에서 나온 것인지 밝힌다.
