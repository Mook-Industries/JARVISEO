# docs — 문서

| 파일 | 무엇 |
|---|---|
| `START_HERE.md` | **새 팀원이 첫 주에 볼 유일한 문서** — 설치 · 매일 쓰는 git · 담당 폴더 |
| `ARCHITECTURE.md` | 뼈대 설명 — 질문 한 번이 코드를 지나가는 길 · 폴더별 역할 · 구현 상태 |
| `ERD.md` | 데이터베이스 설계 — 테이블 · 컬럼 · 관계 |
| `experiments.md` | 실험 기록 — 학습 설정과 결과를 한 줄씩 |
| `meeting/` | 회의록 |

## 규칙

- 설계가 바뀌면 **코드를 먼저 고치고 문서를 맞춘다.** 코드가 실제로 도는 쪽이다.
- 실험을 한 번 돌릴 때마다 `experiments.md` 에 한 줄 남긴다.
  나중에 발표 자료의 비교표가 여기서 나온다.
- 회의록은 `meeting/YYYY-MM-DD.md` 로 만든다.
